# PH2 Dataset Download

DermAssist uses the PH2 dataset for skin lesion image preprocessing.

Download the dataset from the Zenodo page:

https://zenodo.org/records/17498821

## Download Steps

1. Open the Zenodo link.
2. Download the PH2 dataset archive.
3. Extract the archive.
4. Place the dataset in the `PH2/` folder.
5. Keep the expected folder structure.
6. Open and run the notebook from top to bottom.

The original dataset is not included in this GitHub repository.
